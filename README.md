# Luna's Gentoo Dotfiles
## This is just an amalgamation of configurations I've made for Gentoo that I like to use or that I am working on. This is a public repo as with adaptation all these files are absolutely useable on most systems.

# Configs where designed around the following specifications (2 devices) 
### Directory ./luserportable

- AMD Ryzen 5 5500 (6C/12T)
- 16GB LPDDR4X DRAM
- AMD Radeon integrated graphics 
- PCIe Gen 3 SSD
- Where applicable many configurations are made with priority 1 being security 2nd to usability.

### Directory ./luserlab

- AMD Ryzen 5 5500 (6C/12T)
- 32GB DDR4 DRAM 
- Nvidia GTX 1080
- PCIe Gen 3 SSD 
- Where applicable configurations are designed for daily driving on a desktop
